# Demo datasets

Two bundled CSVs in `public/data/`, served to the browser as-is. Both are regenerated by scripts in `scripts/`, so the data is reproducible and its origins are on record.

---

## `bikes.csv` — Santander Cycles journeys, London (real data)

Individual hire journeys on London's public bike scheme: when and where each hire started and ended, how long it took, and whether it was a classic bike or an e-bike. Built from one or more weekly extracts, then randomly sampled down to about 25,000 journeys so the file stays small enough for the browser.

**Source:** Transport for London — journey extracts from `cycling.data.tfl.gov.uk` (usage-stats folder) and station coordinates from the TfL BikePoint API.
**Licence:** TfL's transport data terms (a modified Open Government Licence). Redistribution is allowed. **Attribution required** — show this wherever the dataset is displayed:

Don't use TfL logos or imply the app is an official TfL product.

**Rebuild:**

1. Download two weekly `JourneyDataExtract…csv` files from `cycling.data.tfl.gov.uk` into `data-raw/` (git-ignored) — ideally one summer week and one winter week, as recent as available.
2. Run `node scripts/prepare-bikes.mjs data-raw/*.csv`.
3. Note which files you used in the "Build record" below.

The sample is seeded, so the same input files always produce the same output.

| Column | Kind | Notes |
|---|---|---|
| `start_time` | date | ISO date and time, London local time |
| `date` | date | ISO `YYYY-MM-DD` |
| `weekday` | category | `Mon` … `Sun` |
| `day_type` | category | Weekday · Weekend |
| `hour` | number | 0–23, hour the hire started |
| `season` | category | Winter · Spring · Summer · Autumn |
| `start_station` | category | station name, e.g. "Frith Street, Soho" |
| `start_area` | category | the part after the comma, e.g. "Soho" |
| `start_lat`, `start_lon` | number | station coordinates; blank if the station no longer exists |
| `end_station`, `end_area`, `end_lat`, `end_lon` | | as above, for the end of the hire |
| `round_trip` | category | Yes if returned to the same station |
| `duration_min` | number | hire length in minutes, 1 decimal place |
| `bike_type` | category | Classic · E-bike |

**Cleaning:** hires under a minute that returned to the same dock (false starts) and hires over 24 hours are dropped. Station names are tidied (stray spaces, HTML entities).

**Sampling:** counts in this file are a sample, not TfL totals. The script prints the ratio (e.g. "1 in 13") — record it below, and label charts of counts accordingly.

**What to look for** (typical of the scheme — check once the file is built): weekday commuter peaks around 8am and 6pm against a single afternoon hump at weekends; longer, round-trip leisure rides around Hyde Park and the South Bank; summer against winter volumes; e-bike hires running longer distances; plotting `start_lon` against `start_lat` draws a rough map of the network.

## `gelato.csv` — Gelateria Nebbia, London (invented data)

Daily sales for a **fictional** five-shop London gelato chain, 1 January 2024 – 31 December 2025: one row per shop, flavour and day. 22,964 rows. Every number is generated; the weather is plausible for London but not real.

**Rebuild:** `node scripts/generate-gelato.mjs`. Seeded, so every run produces an identical file.

| Column | Kind | Notes |
|---|---|---|
| `date` | date | ISO `YYYY-MM-DD` |
| `weekday` | category | `Mon` … `Sun` |
| `shop` | category | Covent Garden · Hampstead Heath · Canary Wharf · Brixton · Richmond Riverside |
| `flavour` | category | Pistachio · Stracciatella · Dark Chocolate · Salted Caramel · Amalfi Lemon · Alphonso Mango · Earl Grey |
| `flavour_type` | category | Gelato · Sorbet |
| `scoops` | number | scoops sold |
| `revenue_gbp` | number | pounds |
| `max_temp_c` | number | London's peak temperature that day — same for all shops |
| `rain_mm` | number | rainfall that day |
| `weather` | category | Sunny · Cloudy · Rain |
| `school_holiday` | category | Yes · No (approximate London term dates) |
| `bank_holiday` | category | Yes · No |

**Planted stories** — useful for demo prompts, and for checking the charts show what they should:

- **Heat drives sales, up to a point.** Sales climb steeply from about 15°C, peak around 30°C, then fall on the very hottest days — too hot to queue.
- **Parks and riverside are the most weather-sensitive.** Richmond Riverside and Hampstead Heath swing hardest with heat and rain; Covent Garden, with its tourist trade, is the steadiest.
- **Canary Wharf is the odd one out.** Office-worker trade: busy on weekdays, half as busy at weekends. Every other shop is the reverse.
- **Sorbets win on hot days.** Lemon and mango take a larger share as it warms up; dark chocolate and salted caramel lose share.
- **Heatwaves.** Late July – early August 2024 (the hottest day in the set: 34.8°C, 1 August 2024), and a long spell from 19 June – 1 July 2025. 2025 has more days above 30°C.
- **A new flavour.** Earl Grey launches on 1 May 2025 with a burst of early interest that settles down. No rows exist for it before launch.
- **A closure.** Brixton is shut for a refit from 3 to 23 February 2025 (no rows), then gets a reopening-week bump.
- **A price rise.** Scoops go from £3.60 to £3.95 on 1 April 2025, so revenue grows faster than scoops. Covent Garden charges 30p more, and pistachio 40p more everywhere.
- **Christmas.** All shops closed on Christmas Day; Covent Garden busier through December.
- **Growth.** 2025 runs about 6% ahead of 2024, before weather.
